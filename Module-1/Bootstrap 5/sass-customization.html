Sass Customization

Customize Bootstrap with Sass variables and local build setup

Use npm, Sass, and Bootstrap source files to adjust colors, border radius, and button styling.

Setup with npm

This project includes a local `package.json` and `node_modules` folder for Bootstrap and Sass.

Install dependencies:

npm install

Compile Sass:

npm run build:css

Watch changes:

npm run watch:css

Variables file

Modify `sass/_variables.scss` to change your theme palette and global Bootstrap variables.

$primary: #4f46e5;
$secondary: #0f766e;
$body-bg: #f8fafc;
$border-radius: 1rem;
$btn-border-radius: 2rem;

Bootstrap source import

Use `sass/bootstrap.scss` to import variable overrides before the Bootstrap source.

@import 'variables';
@import '../node_modules/bootstrap/scss/bootstrap';

Custom Sass styles

Add project-specific styles in `sass/custom.scss` and compile your theme into `css/style.css`.

.hero-gradient {
  background: linear-gradient(135deg, #4f46e5, #0ea5e9);
}

.btn-theme {
  background: rgba(79, 70, 229, 0.1);
  border-radius: 50px;
}
