# Local Community Event Portal

## Project Overview
The Local Community Event Portal is a beginner-friendly, browser-based website built with HTML5, CSS3, and vanilla JavaScript. It helps residents discover local events, register for activities, submit feedback, and explore event categories using accessible and responsive design.

## Features
- Responsive layout with mobile, tablet, and desktop support
- Semantic HTML5 structure including header, nav, main, section, article, aside, and footer
- CSS styling with gradients, shadows, animations, pseudo-classes, and responsive media queries
- JavaScript event handling for search filters, form validation, menu toggling, theme switching, and local storage
- Registration and feedback forms with validation logic and status messages
- Event cards loaded dynamically from JavaScript data
- Local storage persistence for registrations and user feedback
- Multimedia support with images, audio, video, and embedded map iframe

## How to Use
1. Open the project folder in VS Code.
2. Open `index.html` in your browser.
3. Navigate between pages using the header menu.
4. Use the search and category filters on the Events page.
5. Complete the Registration and Feedback forms to practice form validation.

## Development Notes
- The code uses external CSS files for layout and styling, plus inline and internal CSS examples for beginner education.
- JavaScript is separated into clear modules for page behavior, event rendering, and form validation.
- The site demonstrates HTML5 forms, tables, lists, multimedia elements, internal navigation, and accessibility best practices.

## Learning Goals
- Understand semantic HTML tags and proper page structure
- Practice CSS layout with Flexbox, Grid, and responsive breakpoints
- Implement JavaScript DOM manipulation, event handling, and validation
- Use local storage to save user data in the browser
- Build a cohesive, modern UI without frameworks
