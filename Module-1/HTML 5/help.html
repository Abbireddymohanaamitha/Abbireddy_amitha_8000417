Community Event Portal Help

Use this page to review the portal features and instructions for common tasks.

  • Open the navigation links to jump between Home, Events, and Contact.
  • Register for an event using the form on the main page.
  • Double-click any gallery image to enlarge it.
  • Use the Find Nearby Events button to request your current location.
  • Clear saved preferences at any time from the registration area.

Need additional assistance? Contact the city council office during business hours.
